# Q2：比较基线模型与改进模型

- 负责人：CODE_LOGIN；建模接口：MODEL_LOGIN；论文接口：PAPER_LOGIN。
- 目标：在相同的数据划分和指标定义下比较两种模型，并说明差异与限制。
- 输入：题目版本、数据来源/授权、数据校验值、预处理约定、模型公式链接（由团队填入）。
- 范围：实现和比较已约定模型；假设或评价方式变化先在 Issue 说明。
- 输出：实验脚本、环境依赖、可复现结果表、图表、论文可引用结论。
- 验收：给出代码提交、运行命令、随机种子、划分方式、样本数、指标定义和单位；区分实际运行与未验证推断；检查数据泄漏。
- 交付：PR 链接与固定提交的结果文件；剩余问题和下一位接手人。
- 截止时间：由团队填写，注明时区。
